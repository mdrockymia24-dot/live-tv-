# 📺 Toffee Auto IPTV Generator

Toffee-র সব লাইভ টিভি চ্যানেল (ফ্রি ও প্রিমিয়াম পেইড চ্যানেল সহ) স্বয়ংক্রিয়ভাবে সংগ্রহ করে একটি সম্পূর্ণ কার্যক্ষম M3U প্লেলিস্ট তৈরি করার স্বয়ংক্রিয় স্ক্রিপ্ট।

GitHub Actions-এর মাধ্যমে প্রতি ১ ঘণ্টা পর পর এটি স্বয়ংক্রিয়ভাবে রান হয়ে `toffee.m3u` ফাইলটি আপডেট করে রাখবে।
